## 📖 Sobre o projeto

Este repositório registra o desenvolvimento do meu primeiro jogo utilizando a Godot Engine.

O projeto faz parte do meu processo de aprendizado em desenvolvimento de jogos, começando desde os conceitos básicos da engine e avançando gradualmente para programação, criação de cenas, movimentação, colisões, animações e outras mecânicas.

Estou utilizando um tutorial como base de estudos e, conforme avanço nas aulas, pretendo colocar em prática os conhecimentos adquiridos e experimentar minhas próprias ideias dentro do projeto.

## 🚧 Projeto em desenvolvimento.

Este é um projeto de aprendizado e representa meu primeiro contato com desenvolvimento de jogos utilizando a Godot.

## 🎯 Objetivo

O principal objetivo deste projeto é aprender desenvolvimento de jogos na prática.

Em vez de tentar aprender todos os conceitos antes de começar, estou seguindo um processo de:

Aprender → Praticar → Testar → Errar → Corrigir → Evoluir

Este projeto também servirá como um registro da minha evolução, permitindo acompanhar desde os primeiros passos até uma primeira versão jogável.

## ▶️ Como executar o projeto
Requisitos

Godot Engine 4.8

Git

Clone o repositório
git clone https://github.com/Estevao-exe/meu-jogo.git


Entre na pasta:

cd meu-jogo


Depois, abra o projeto através da Godot Engine.

Para executar:

F5 → Executar o projeto


Ou:

F6 → Executar a cena atual
