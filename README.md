🎮 Meu Primeiro Jogo na Godot

Este repositório é o registro do meu primeiro projeto desenvolvido utilizando a Godot Engine.

Estou começando a aprender desenvolvimento de jogos desde o básico, explorando a engine, sua interface, criação de projetos, cenas, scripts e os principais conceitos necessários para desenvolver um jogo.

🚧 Projeto em desenvolvimento — este repositório acompanha minha evolução durante os estudos.

📚 Sobre o projeto

Este projeto está sendo desenvolvido enquanto acompanho as aulas do tutorial:

🎥 Tutorial Godot do Zero 2025
🔗 Assistir à aula no YouTube

A ideia não é apenas copiar o projeto, mas entender aos poucos como a Godot funciona, praticando os conceitos apresentados nas aulas e fazendo minhas próprias experiências durante o desenvolvimento.
